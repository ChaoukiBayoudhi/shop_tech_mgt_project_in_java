# Shop tech management project in Java

A Java console application.

## Tech stack

- Java
- Lombok

## Concepts covered

Console input (Scanner), inheritance.

## Project structure

- `Equipments`: Equipment
- `details`: Constructor, Microprocessor, Screen
- `enumerations`: ComputerBrand, EquipmentState, MicroprocessorBrand, PrinterBrand, PrinterType
- `pc_mgt`: Computer
- `printer_mgt`: Printer
- `program`: Main
- `smartphone_mgt`: Smartphone

## How to run

Open the folder in IntelliJ IDEA or Eclipse and run `Main` (it contains the `main` method).

The code uses Lombok annotations: add the Lombok library and enable annotation processing in your IDE.
